# Tamagotchi

Un pequeño juego de tamagotchi implementado con una máquina de estados y HTML, CSS y JavaScript puro.

## Características

- Sistema de estados: feliz, comiendo, jugando, limpiándose, durmiendo, hambriento, sucio, somnoliento, enfermo y muerto.
- Barra de estadísticas para hambre, felicidad, limpieza, energía y salud.
- Interacciones con botones para cuidar al personaje.
- Bloqueo de acciones mientras se ejecuta otra habilidad.
- Visual estilo pet con CSS sin librerías externas.

## Estructura del proyecto

- `index.html`: estructura principal de la interfaz.
- `style.css`: estilos del juego.
- `script.js`: lógica del tamagotchi y la máquina de estados.

## Cómo ejecutar

Abre el archivo `index.html` en tu navegador, o ejecuta un servidor local:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Objetivo

Mantén a Mochi feliz y saludable cuidando de sus necesidades.
